# Network Evolution: от первого узла до экосистемы

## Стадии роста

Каждая стадия меняет не только количество узлов, но и **экономические роли**,
**доступные сервисы** и **социальную структуру**.

---

## Стадия 0: Pre-seed (1-5 узлов, 0-2 месяца)

```
Участники:
  ┌────────────┬──────────┬──────────┬─────────────────────────────┐
  │ Роль       │ Железо   │ Доход    │ Что делает                   │
  ├────────────┼──────────┼──────────┼─────────────────────────────┤
  │ Разработчик│ Роутер   │ 0        │ Тестирует протокол, чинит    │
  │            │ + ESP32  │ (эмиссия │ баги, пишет документацию     │
  │            │          │  в минус)│                              │
  ├────────────┼──────────┼──────────┼─────────────────────────────┤
  │ Тестеры    │ Роутер   │ 0        │ Гоняют чат, ломают,          │
  │ (2-3 чел)  │ из коробки│         │ сообщают о багах             │
  └────────────┴──────────┴──────────┴─────────────────────────────┘

Экономика:
  - RELAY не циркулируют (все друг друга знают)
  - Confirm-N генерирует emission, но тратить некуда
  - Балансы: все около нуля

Сервисы:
  - Только текстовый чат
  - WebUI для диагностики

Проблемы:
  - Нестабильность (баги, перезагрузки)
  - Нет резервирования (упал узел = тишина)
```

## Стадия 1: Ранняя сеть (10-50 узлов, 2-6 месяцев)

```
Участники:
  ┌──────────────┬──────────┬──────────┬───────────────────────────┐
  │ Роль         │ Железо   │ Доход    │ Что делает                 │
  ├──────────────┼──────────┼──────────┼───────────────────────────┤
  │ Ранние поль- │ Роутер   │ ~10-50   │ Чат, обмен файлами        │
  │ зователи     │ из коробки│ RELAY/день│                           │
  │ (70%)        │          │          │                            │
  ├──────────────┼──────────┼──────────┼───────────────────────────┤
  │ Активные     │ Роутер   │ ~100-300 │ Много relay'ят, мало      │
  │ relay'еры    │ + ESP32  │ RELAY/день│ отправляют                │
  │ (20%)        │          │          │                            │
  ├──────────────┼──────────┼──────────┼───────────────────────────┤
  │ Разработчик  │ Роутер   │ 0        │ Поддержка, обновления,     │
  │              │ + ПК     │ (в минус)│ ответы на вопросы          │
  ├──────────────┼──────────┼──────────┼───────────────────────────┤
  │ Хранители    │ Роутер   │ ~50-100  │ Первые зеркала: хранят     │
  │ (10%)        │ + флешка │ RELAY/день│ контент, DHT-записи       │
  └──────────────┴──────────┴──────────┴───────────────────────────┘

Экономика:
  - RELAY начинают циркулировать (есть спрос на relay)
  - Первые трансферы: зелёные → красным
  - STORAGE_REWARD активируется (первые зеркала)
  - Цена RELAY: чисто внутренняя, нет внешнего рынка

Сервисы:
  - Чат (групповой, личный)
  - Файлообменник (первые PDF'ки, фото)
  - Каталог узлов (кто онлайн)
  - Простейший форум (один узел хостит)

Проблемы:
  - Неравномерное покрытие (все на 1-2 этажах)
  - Асимметричные линки (разные антенны)
  - "А где все?" — ночью сеть пустеет
```

## Стадия 2: Рабочая сеть (50-200 узлов, 6-12 месяцев)

```
Участники:
  ┌──────────────┬──────────┬──────────┬───────────────────────────┐
  │ Роль         │ Железо   │ Доход    │ Что делает                 │
  ├──────────────┼──────────┼──────────┼───────────────────────────┤
  │ Обычные      │ Роутер   │ ~10-30   │ Чат, файлы, серфинг       │
  │ пользователи │ из коробки│ RELAY/день│ .mesh-сайтов             │
  │ (60%)        │          │          │                            │
  ├──────────────┼──────────┼──────────┼───────────────────────────┤
  │ Relay-узлы   │ Роутер   │ ~100-500 │ Стратегически размещены    │
  │ (25%)        │ + ESP32  │ RELAY/день│ (верхние этажи, окна)     │
  ├──────────────┼──────────┼──────────┼───────────────────────────┤
  │ Зеркала      │ Роутер   │ ~200-500 │ Хранят контент + DHT,     │
  │ (10%)        │ + флешка │ RELAY/день│ экономят память другим     │
  │              │ 32 GB    │          │                            │
  ├──────────────┼──────────┼──────────┼───────────────────────────┤
  │ Хостеры      │ ПК/ноут  │ ~0-100   │ Держат сайты: вики,        │
  │ (3%)         │ + роутер │ RELAY/день│ форум, файлообменник      │
  ├──────────────┼──────────┼──────────┼───────────────────────────┤
  │ Bridge-      │ Роутер   │ ~500-    │ Выход в интернет,          │
  │ операторы    │ + Ethernet│ 2000     │ внешние сообщения,         │
  │ (2%)         │ + VPN    │ RELAY/день│ обменник RELAY↔рубли      │
  └──────────────┴──────────┴──────────┴───────────────────────────┘

Экономика:
  - Полноценная циркуляция RELAY
  - Появляются первые обменники (RELAY↔рубли)
  - STORAGE_REWARD + DHT_MIRROR_REWARD — стабильный доход зеркал
  - Bridge-операторы окупают интернет
  - Adoption loop: больше узлов → дешевле RELAY → больше пользователей

Сервисы:
  - Несколько .mesh-сайтов (вики, форум, каталог)
  - Локальный поиск (по сайтам, файлам, пользователям)
  - Внешняя почта (через bridge: отправить/получить email)
  - Обменник RELAY (первые рыночные курсы)

Проблемы:
  - "Трагедия общих пастбищ": relay-очереди переполнены в пики
  - Первые конфликты: кто чей сайт "угнал" (self-certifying names решают)
  - Непонятно "сколько реально стоит RELAY"
```

## Стадия 3: Зрелая сеть (200-1000 узлов, 1-2 года)

```
Участники:
  ┌──────────────┬──────────┬──────────┬───────────────────────────┐
  │ Роль         │ Железо   │ Доход    │ Что делает                 │
  ├──────────────┼──────────┼──────────┼───────────────────────────┤
  │ Пользователи │ Роутер   │ ~5-15    │ Чат, сайты, файлы, почта   │
  │ (50%)        │ из коробки│ RELAY/день│                           │
  ├──────────────┼──────────┼──────────┼───────────────────────────┤
  │ Relay-фермы  │ Несколько│ ~1000-   │ Профессиональные relay'еры │
  │ (5%)         │ роутеров │ 5000     │ Свои кластеры, backbone    │
  │              │ + rooftop│ RELAY/день│                            │
  ├──────────────┼──────────┼──────────┼───────────────────────────┤
  │ Дата-центры  │ ПК + SSD │ ~2000-   │ Хранят терабайты контента, │
  │ (2%)         │ + гигабит│ 10000    │ DHT-зеркала, CDN для сайтов│
  ├──────────────┼──────────┼──────────┼───────────────────────────┤
  │ Сервис-      │ VPS/ПК   │ ~500-    │ Хостят десятки сайтов,     │
  │ провайдеры   │ + роутер │ 5000     │ API, базы данных            │
  │ (3%)         │          │ RELAY/день│                           │
  ├──────────────┼──────────┼──────────┼───────────────────────────┤
  │ Bridge-      │ Роутер   │ ~2000-   │ Профессиональные мосты:    │
  │ операторы    │ + сервер │ 10000    │ интернет, другие mesh'и,    │
  │ (2%)         │          │ RELAY/день│ обменники                  │
  ├──────────────┼──────────┼──────────┼───────────────────────────┤
  │ Разработчики │ ПК       │ ~0-1000  │ Пишут приложения, сервисы,  │
  │ (3%)         │          │ RELAY/день│ плагины, форки прошивки    │
  ├──────────────┼──────────┼──────────┼───────────────────────────┤
  │ Кланы/       │ Смешанное│ ~0 (не   │ Социальная организация,    │
  │ суверенитеты │          │ про доход)│ взаимопомощь, модерация    │
  │ (35%)        │          │          │                            │
  └──────────────┴──────────┴──────────┴───────────────────────────┘

Экономика:
  - Рынок RELAY стабилен (цена привязана к электричеству)
  - Профессиональные relay-фермы (эффект масштаба)
  - Арбитраж между обменниками (разные курсы → трейдеры выравнивают)
  - "Майнеры" (relay-фермы) конкурируют за трафик
  - Хранилища-как-сервис (S3-like API поверх контент-слоя)

Сервисы:
  - Десятки .mesh-сайтов (новости, вики, торговая площадка)
  - Почта с внешним миром (через bridge)
  - Платежи (RELAY + внешняя крипта через bridge)
  - Федерация с другими mesh-сетями (модуль 38)
  - Поисковая система по .mesh

Проблемы:
  - "Слишком большой чтобы упасть": топ-5 relay-ферм держат 60% трафика
  - Централизация через удобство: официальный обменник вытесняет мелкие
  - Регуляторное давление (администрация зоны пытается контролировать)
  - Форки протокола (кто-то сделал "rmn-fast" с другими параметрами)
```

## Стадия 4: Экосистема (1000+ узлов, 2+ года)

```
Участники:
  ┌────────────────┬──────────┬──────────┬─────────────────────────┐
  │ Роль           │ Железо   │ Доход    │ Что делает               │
  ├────────────────┼──────────┼──────────┼─────────────────────────┤
  │ Пользователи   │ Любое    │ ~0-5     │ Всё: чат, сайты, файлы,  │
  │ (45%)          │          │ RELAY/день│ почта, платежи, игры     │
  ├────────────────┼──────────┼──────────┼─────────────────────────┤
  │ Инфраструктура │ Кластеры │ ~5000-   │ Backbone сети, аренда    │
  │ (5%)           │          │ 50000    │ relay-мощности, CDN      │
  ├────────────────┼──────────┼──────────┼─────────────────────────┤
  │ Бизнесы (3%)   │ Смешанное│ ~0-      │ Продажа товаров/услуг    │
  │                │          │ 100000   │ за RELAY, обменники      │
  ├────────────────┼──────────┼──────────┼─────────────────────────┤
  │ Медиа (2%)     │ VPS/ПК   │ ~0-5000  │ Новостные сайты, блоги,  │
  │                │          │          │ стриминг (аудио)         │
  ├────────────────┼──────────┼──────────┼─────────────────────────┤
  │ Разработчики   │ ПК       │ ~0-10000 │ Десятки приложений,      │
  │ (5%)           │          │          │ свои прошивки, контракты  │
  ├────────────────┼──────────┼──────────┼─────────────────────────┤
  │ Федеративные   │ Bridge-  │ ~10000-  │ Связь с другими mesh'ами │
  │ bridge'и (1%)  │ серверы  │ 50000    │ и внешним интернетом     │
  └────────────────┴──────────┴──────────┴─────────────────────────┘

Экономика:
  - RELAY — полноценная валюта (обмен на рубли, USDT, BTC)
  - Фьючерсы на relay-мощность (купи сейчас, используй в пик)
  - Кредитование: "дай 1000 RELAY на развитие фермы, верну 1200 через месяц"
  - Рынок репутации: аккаунты с высоким reputation продаются
  - Страхование: "заплати 10 RELAY/мес — если узел упадёт, ферма подхватит"

Сервисы:
  - Сотни .mesh-сайтов (новости, соцсети, маркетплейсы, банки)
  - Стриминг (аудио, может лёгкое видео по WiFi)
  - IoT-интеграция (умные лампочки, датчики, камеры — всё на RMN)
  - VPN-выход в интернет (bridge как VPN-провайдер)
  - Децентрализованные приложения (dApps) на RMN

Проблемы:
  - Регуляторное давление (государство пытается регулировать)
  - Монополизация (топ-3 инфраструктурных оператора)
  - Технический долг (протоколу 2+ года, легаси-узлы)
  - Кибервойны (DDoS через Sybil-узлы, целевые атаки на bridge'и)
```
