# Hardware & Product Design

## От прототипа к продукту

Три уровня зрелости — от софта до специализированного железа.

## Уровень 1: Software-Only (существующее железо)

### Минимальные требования

```
Роутер:
  - OpenWRT-совместимый (TP-Link, Xiaomi, GL.iNet)
  - 64+ MB RAM
  - 8+ MB flash
  - WiFi 2.4 GHz (обязательно)

LoRa-модуль (внешний):
  - ESP32 + SX1276/78
  - Подключение: USB/UART к роутеру
  - Цена: ~$12-15

Итого: ~$35-45 за комплект
```

### Прошивка

```
1. OpenWRT (стандартная прошивка)
2. Пакет rmn-node (Go binary, кросс-компиляция под MIPS/ARM)
3. Скрипт авто-конфигурации:
   - Сканирует LoRa-модуль на /dev/ttyUSB0
   - Поднимает WiFi AP "RMN-XXXX"
   - Запускает WebUI на 10.42.0.1:8080
```

## Уровень 2: DIY Kit (для энтузиастов)

```
Комплект:
  - Роутер (предпрошитый OpenWRT + RMN)
  - LoRa-модуль (предпрошитый ESP32)
  - Антенна (SMA, 3 dBi)
  - USB-кабель
  - Инструкция (QR-код → видео/гайд)

Цена: ~$40-50
```

## Уровень 3: Специализированные устройства

### Модель A: "RelayStation" — идеальный relay-узел

```
Назначение: майнинг трафика, backbone между зданиями

Железо:
  - CPU: Raspberry Pi Zero 2 W / Orange Pi (1 GHz, 512 MB RAM)
  - Radio: SX1262 (LoRa) + 5 dBi антенна
  - WiFi: опционально (только для управления)
  - Ethernet: 1× 100 Mbps (backbone)
  - Питание: 5V USB-C или PoE
  - Корпус: погодозащищённый (для rooftop)

Характеристики:
  - Дальность LoRa: до 5-10 км (SF12, 5 dBi)
  - Пропускная способность: до 50 кбит/с (SF7)
  - Потребление: ~3-5 Вт
  - Цена: ~$30-40 (без антенны)

Режимы:
  - Backbone: соединяет здания через LoRa + Ethernet
  - Indoor relay: внутри здания, только relay
  - Rooftop: на крыше, максимальный охват
```

### Модель B: "MeshNode" — пользовательский узел

```
Назначение: в комнате пользователПользователстудента, точка доступа в mesh

Железо:
  - CPU: MediaTek MT7620/7621 (стандартный роутерный SoC)
  - RAM: 128 MB
  - Flash: 16 MB
  - WiFi: 2.4 GHz AP + Client
  - LoRa: встроенный SX1276
  - Ethernet: 2× 100 Mbps
  - USB: 1× для флешки (контент-слой)
  - Питание: 5V micro-USB

Характеристики:
  - WiFi дальность: ~50-100 м (внутри здания)
  - LoRa дальность: ~1-2 км (SF7)
  - Потребление: ~5-7 Вт
  - Цена: ~$40-50

Особенности:
  - Прошивка "из коробки" — включил и работает
  - WebUI на 10.42.0.1
  - Гостевая WiFi-сеть "RMN-Guest"
  - Светодиодная индикация: статус mesh, баланс, relay-активность
```

### Модель C: "MeshStick" — портативный relay

```
Назначение: носить с собой, подключать к телефону через WiFi

Железо:
  - SoC: ESP32-S3 (dual core, WiFi + BLE)
  - LoRa: SX1262
  - Аккумулятор: 500 mAh (6-8 часов работы)
  - Размер: спичечный коробок (50×25×15 мм)
  - Питание: USB-C зарядка

Характеристики:
  - Дальность LoRa: ~1-3 км
  - Потребление: ~0.5 Вт
  - Цена: ~$20-25

Режимы:
  - Mobile relay: носишь в кармане, релеишь трафик
  - Bridge: подключаешь к телефону → телефон в mesh через WiFi
  - Beacon: announce-only для обнаружения сети
```

## Модульность

### Взаимодействие моделей

```
[RelayStation] ←──Ethernet──→ [RelayStation]
      │                            │
      │ LoRa                       │ LoRa
      ▼                            ▼
[MeshNode] ←──WiFi──→ [MeshNode] ←──WiFi──→ [MeshStick] ←──WiFi──→ [Phone]
      │
      ├──USB──→ [Flash Drive] (контент-слой)
      └──Ethernet──→ [PC/Host] (веб-сервер)
```

### Подключаемые модули

```
MeshNode:
  ├── USB-флешка:     контент-слой, до 256 GB
  ├── Внешняя антенна: SMA-разъём, замена штатной
  ├── Ethernet-кабель: backbone до другого узла
  └── PoE-сплиттер:    питание по Ethernet

RelayStation:
  ├── Направленная антенна: Yagi, 10 dBi, для точка-точка
  ├── PoE-инжектор:   питание по тому же кабелю
  └── Солнечная панель: автономное питание на крыше
```

## Частоты и регионализация

```
EU (868 МГц):
  - LoRa: 868.0-868.6 МГц, duty cycle 1%
  - Max TX power: 14 dBm (25 mW)

US (915 МГц):
  - LoRa: 902-928 МГц, duty cycle 100%
  - Max TX power: 30 dBm (1 W) с frequency hopping

Frequency Hopping (доп. защита):
  - 16 каналов по 200 кГц
  - Смена каждую секунду
  - Seed синхронизируется при HELLO
  - При потере синхронизации → fallback на общий канал
```

## Roadmap

```
Фаза 1 (Прототип):
  - Software-only на OpenWRT
  - Тестирование на 3-5 узлах
  - Результат: чат работает, relay работает

Фаза 2 (DIY Kit):
  - Гайд "собери сам"
  - Предпрошитые LoRa-модули
  - Результат: 10-50 узлов, mesh стабилен

Фаза 3 (MeshNode):
  - Первая партия (100 шт.)
  - Раздача через сарафанное радио
  - Результат: 100+ узлов, экономика работает

Фаза 4 (RelayStation + MeshStick):
  - Backbone между зданиями
  - Мобильные relay'и
  - Результат: полное покрытие, роуминг
```
