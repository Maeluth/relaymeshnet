# L4: Устройства, Узлы и Хосты

## Три типа участников

| Тип | Железо | Релеит? | Хостит? | Баланс |
|---|---|---|---|---|
| **Device** | Телефон, ноутбук (клиент) | Нет | Нет | Только тратит |
| **Node** | Роутер OpenWRT + LoRa | Да | Лёгкие сервисы | Только зарабатывает |
| **Host** | ПК/ноутбук (full node) | Опционально | Полноценные сервисы | Зарабатывает и тратит |

## Device → Node: отправка сообщения

```
Устройство подключается к ЛЮБОМУ узлу по WiFi.
Узел принимает пакет и релеит его через mesh.

Экономика:
  Устройство платит:  SEND_COST (hops × KB × 1 credit)
  Узел получает:      RELAY_REWARD (обычная relay-оплата, без наценок)

Узел зарабатывает ровно столько же, сколько на любом relay-пакете.
Никаких дополнительных комиссий (PROXY_FEE).
```

## Transfer: Node → Device

```
Владелец узла переводит заработанные RELAY на своё устройство:

transfer(100 RELAY, from=Node, to=Device)
  → Маршрут через mesh (обычный onion, 3 hop)
  → Node платит SEND_COST за перевод
  → Device получает 100 RELAY
```

## Хостинг: Node (лёгкий) vs Host (полноценный)

### Node (роутер)
- Статика сервиса → через контент-слой (кеш на соседях)
- API-запросы → проксирует на Host владельца
- DNS-like резолвинг `.mesh` имён
- Каталог сервисов (read-only копия из DHT)

### Host (ПК/ноутбук)
- Полноценный веб-сервер (Apache/nginx/Caddy)
- База данных
- API-сервер с бизнес-логикой
- Регистрация в DHT как владелец сервиса
- Может быть relay-узлом (если подключён LoRa-модуль)
- Может быть ТОЛЬКО сервером (режим `--mode host --no-relay`)

## Аутентификация устройства на узле

```
1. Устройство подключается к WiFi узла
2. Узел: "Докажи что ты — это ты"
   → Устройство подписывает challenge своим приватным ключом
3. Узел проверяет в DHT: peerID валиден
4. Сессия создана
5. Все списания — с баланса устройства, не узла
```

## Гостевой режим (без аутентификации)

Для случаев, когда у пользователя нет своего ключа:

```
Гость:
  → Только confirm-N сообщения (бесплатно)
  → Не более 10 сообщений в час
  → Нет доступа к файлам и RELAY-транзакциям
```

## Параметры

| Параметр | Значение | Описание |
|---|---|---|
| `GUEST_MSG_LIMIT` | 10/час | Лимит сообщений для неаутентифицированного гостя |
| `GUEST_FILE_ACCESS` | false | Гость без аутентификации не может отправлять файлы |
| `DEVICE_TRANSFER_HOPS` | 3 | Хопов для перевода Node → Device |
