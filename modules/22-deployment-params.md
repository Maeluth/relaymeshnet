# Deployment: Практические параметры

Результаты исследования реальных условий для развёртывания RMN в РФ.

## Частоты и закон (РФ)

| Параметр | Без регистрации | С регистрацией РЭС |
|---|---|---|
| Диапазон | 868.7-869.2 МГц | 868.7-869.2 МГц |
| Мощность (ЭИИМ) | ≤ 25 мВт (14 dBm) | ≤ 100 мВт (20 dBm) |
| Антенна | Стоковая ~2 dBi | До 5-8 dBi (с учётом EIRP) |
| Duty Cycle | LBT обязателен | LBT или DC ≤ 10% |
| Регистрация | Не требуется | Роскомнадзор (бесплатно через Госуслуги) |
| Штраф за нарушение | — | 1500-3000₽ (ч.2 ст.13.4 КоАП) |

### Расчёт EIRP

```
EIRP (dBm) = TX_Power (dBm) + Antenna_Gain (dBi) − Cable_Loss (dB)

Без регистрации (≤ 14 dBm):
  TX 12 dBm + сток 2 dBi = 14 dBm ✓
  TX 10 dBm + антенна 4 dBi = 14 dBm ✓
  TX 14 dBm + сток 2 dBi = 16 dBm ✗ (нужна регистрация)

С регистрацией (≤ 20 dBm):
  TX 14 dBm + антенна 6 dBi = 20 dBm ✓
  TX 20 dBm + сток 2 dBi = 22 dBm ✗ (превышение ГКРЧ)
```

### Важно

- Регион `RU` (НЕ `EU_868` — другой поддиапазон!)
- Meshtastic firmware: RU = 868.7-869.2 МГц, LBT=true, DC=100%
- Вблизи аэропортов, военных объектов, приграничных зон — запрещено

## Дальность LoRa (реальные тесты)

| Среда | Дальность | Условия |
|---|---|---|
| Открытая местность | 5-10 км | SF12, 14 dBm, прямая видимость |
| Городская застройка | 1.2 км | СПб, Невский район |
| Кампус/кампусе | 2-5 км | Антенна на крыше, 10 dBi |
| Через железобетон | 50-100 м | Сильное затухание |
| Через кирпич | 200-500 м | Умеренное затухание |
| Подвал → крыша | 2 км | Антенна на высоте 4 м |
| Рекорд (море) | 1336 км | Идеальные условия |
| Рекорд (аэростат) | 832 км | Высота 38 км |

### Что это значит для кампуся

```
5-этажное кампусе (20×50 м):
  - Внутри здания: связь есть ВЕЗДЕ (даже через ж/б)
  - Между корпусами (100-500 м): стабильно на SF7-SF9
  - До соседнего квартала (1-2 км): SF12
  - Rooftop-узел: покрывает весь кампус

Вывод: LoRa достаточно для indoor + inter-building mesh.
```

## Кросс-компиляция Go под OpenWRT

```bash
# MIPS (большинство роутеров)
GOOS=linux GOARCH=mipsle GOMIPS=softfloat go build -ldflags="-s -w" -o rmn-node

# ARM (более новые роутеры)
GOOS=linux GOARCH=arm GOARM=7 go build -ldflags="-s -w" -o rmn-node

# Уменьшение размера
upx --best rmn-node  # с 12 MB до ~3 MB
```

Статическая линковка (без внешних зависимостей). Бинарник помещается в /tmp роутера (RAM-диск).

## ESP32 + SX1276 (LoRa-транспорт)

```
Подключение (SPI):
  ESP32       SX1276
  GPIO5  →    SCK
  GPIO19 →    MISO
  GPIO27 →    MOSI
  GPIO18 →    NSS (CS)
  GPIO26 →    DIO0 (прерывание)
  GPIO14 →    RST

Питание: 3.3V (НЕ 5V!)
```

### Выбор режима

- **Raw LoRa** (arduino-LoRa library) — для RMN. Прямая packet radio, без LoRaWAN-стека
- **LoRaWAN** (LMIC) — для совместимости с TTN/Helium. НЕ нужен для RMN

### Serial-протокол ESP32 ↔ Роутер

```
Формат: [Length:2][Type:1][Payload:...][CRC:2]
Baudrate: 115200

Типы сообщений:
  0x01 — LoRa-пакет на отправку
  0x02 — Принятый LoRa-пакет
  0x03 — Статус (RSSI, SNR, частота)
  0x04 — Конфигурация (частота, SF, мощность)
```

## PoE для outdoor-узлов

```
Rooftop-узел:
  - Роутер + ESP32: ~5-7 Вт
  - PoE 802.3af (15.4 Вт) — достаточно
  - IP66 корпус
  - Грозозащита: обязательна (разрядники на антенну и Ethernet)
  - Заземление: обязательно
  - Диапазон температур: −30...+60°C (промышленный роутер)
```

## Антенны

| Тип | Усиление | Применение |
|---|---|---|
| Стоковая (штыревая) | 2 dBi | Внутри комнаты |
| Коллинеарная | 5-8 dBi | Rooftop, всенаправленная |
| Yagi-Uda | 8-14 dBi | Между корпусами, направленная |
| Секторная | 10-18 dBi | Покрытие территории |
| Параболическая | 15-26 dBi | Магистраль 5+ км |

## Рекомендации по развёртыванию

### Indoor (комната)
- Мощность: 12 dBm (без регистрации)
- Антенна: стоковая 2 dBi
- EIRP: 14 dBm = 25 мВт — легально

### Rooftop (крыша)
- Мощность: 14 dBm
- Антенна: коллинеарная 5 dBi
- EIRP: 19 dBm — нужна регистрация РЭС
- Питание: PoE
- Грозозащита + заземление

### Backbone (между зданиями)
- Мощность: 14-20 dBm
- Антенна: Yagi 8-10 dBi, направленная
- Высота: максимальная (крыша)
- Регистрация обязательна (> 25 мВт EIRP)
