# Node Lifecycle

## Путь узла: от включения до доверенного relay

Каждый узел проходит через предсказуемые стадии жизненного цикла.
Стадия определяет: возможности, ограничения, веса в relay-выборе, credit limit.

```
                         ┌─────────────────┐
          включение       │    BOOTSTRAP    │
    ─────────────────────→│   (0-5 минут)   │
                         └────────┬────────┘
                                  │ найден первый сосед
                                  ▼
                         ┌─────────────────┐
                         │    SANDBOX      │
                         │   (0-7 дней)    │
                         └────────┬────────┘
                                  │ репутация > 0
                                  ▼
                         ┌─────────────────┐
                         │    RAMP-UP      │
                         │   (7-30 дней)   │
                         └────────┬────────┘
                                  │ репутация > порог
                                  ▼
                         ┌─────────────────┐
                         │    ACTIVE       │
                         │  (30+ дней)     │
                         └────────┬────────┘
                                  │ репутация > высокий порог
                                  ▼
                         ┌─────────────────┐
                         │    TRUSTED      │
                         │  (90+ дней)     │
                         └─────────────────┘
```

## Стадии

### BOOTSTRAP (0-5 минут)

```
Состояние: только что включён, не знает ни одного пира.

Действия:
  1. Сканирует WiFi (SSID "RMN-*") и LoRa (JOIN REQUEST на SF12)
  2. Находит первый узел → HELLO handshake
  3. Получает peer list, начинает gossip
  4. Скачивает DHT-записи для своей XOR-зоны

Ограничения: никаких — это техническая фаза, не экономическая.
```

### SANDBOX (0-7 дней)

```
Состояние: новый узел, репутация = 0.

Экономика:
  - Эмиссия confirm-N: заблокирована в escrow (накапливается)
  - Relay-вознаграждение: ×1.0 (полное, НЕ урезается)
  - Credit limit = 0 (не может уйти в минус)
  - Не может отправлять файлы > 10 KB (только текст через confirm-N)
  - Не может переводить RELAY другим узлам

Relay-выбор:
  - Репутация 0 → вес в relay-выборе минимальный
  - Может быть выбран только если нет узлов с репутацией > 0
  - На практике: почти не выбирается, пока не накопит репутацию

Зачем: защита от Sybil-атак. Злоумышленник не может мгновенно
  получить relay-трафик на новом узле.
```

### RAMP-UP (7-30 дней)

```
Состояние: репутация > 0, escrow разблокирован.

Экономика:
  - Escrow сбрасывается на баланс (накопленная эмиссия за sandbox)
  - Credit limit = 20 × sqrt(reputation)
  - Может отправлять файлы любого размера (в пределах credit limit)
  - Может переводить RELAY (до credit limit)

Relay-выбор:
  - Репутация > 0 → участвует в relay-выборе
  - Вес пропорционален репутации
  - Постепенно начинает получать relay-трафик
```

### ACTIVE (30-90 дней)

```
Состояние: полноценный участник сети.

Экономика:
  - Все ограничения сняты
  - Credit limit = 20 × sqrt(reputation)
  - Полный доступ ко всем функциям

Relay-выбор:
  - Полный вес в relay-выборе (reputation × node_class_weight)
  - Может быть выбран для DHT-хранения (если достаточно репутации)
```

### TRUSTED (90+ дней)

```
Состояние: проверенный временем узел.

Дополнительные возможности:
  - Может быть выбран как DHT-хранитель ключей (повышенная ответственность)
  - Может "поручиться" за новый узел (vouch — выделить часть credit limit)
  - Приоритет в gossip-распространении (его голос весомее)

Vouch-механика:
  - TRUSTED узел может выделить до 10% своего credit limit новичку
  - Новичок получает credit line раньше (не ждёт 7 дней sandbox)
  - Если новичок уходит в минус и бросает сеть — vouch-узел теряет репутацию
  - Это социальный механизм: TRUSTED узлы ручаются за тех, кого знают лично
```

## Переходы между стадиями

```
BOOTSTRAP → SANDBOX:      автоматически при первом HELLO
SANDBOX → RAMP-UP:        требуется 7 дней И репутация > 0
RAMP-UP → ACTIVE:         требуется 30 дней
ACTIVE → TRUSTED:         требуется 90 дней И репутация > порог

Возврат в SANDBOX:
  - Узел был офлайн > 30 дней → при возврате начинает с SANDBOX
  - Reputation демередж за время офлайна (×2) съедает большую часть
  - Баланс сохраняется (заработан честно)
  - PoH age gap: видно что узел не работал
```

## Параметры

| Параметр | Значение | Описание |
|---|---|---|
| `SANDBOX_DURATION` | 7 дней | Новый узел в sandbox |
| `RAMPUP_DURATION` | 30 дней | Переходный период |
| `TRUSTED_THRESHOLD` | 90 дней | Минимальный возраст для TRUSTED |
| `ESCROW_UNLOCK` | 7 дней | Когда разблокируется накопленная эмиссия |
| `VOUCH_MAX_PERCENT` | 10% | Максимальная доля credit limit для vouch |
| `OFFLINE_RESET` | 30 дней | Офлайн дольше → возврат в SANDBOX |
